Backup e Restauração

Exportar Backup

Salva todos os clientes, serviços e configurações em um arquivo JSON. O backup inclui dados financeiros e deve ser guardado com segurança.

Restaurar Backup

Importa dados de um arquivo de backup JSON. Os dados atuais serão substituídos após confirmação.

Informações Importantes

  • Faça backups regulares (semanalmente ou após alterações importantes)
  • O arquivo de backup contém nomes, telefones, endereços e valores financeiros
  • Guarde o backup em local seguro (nuvem pessoal, pen drive, e-mail)
  • A restauração substitui todos os dados atuais
  • Teste a restauração periodicamente para garantir integridade
  • O formato CSV não permite restauração, apenas visualização
